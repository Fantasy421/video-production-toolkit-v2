# Video Production Toolkit V2

一个以“主动推荐 + 用户选择”为核心的 Codex 视频制作插件。

它根据内容目标、受众、发布平台、真实配音时长、已有素材和制作成本，先给出一套可以直接接受的推荐方案，再引导用户完成台词、声音、分镜、风格和预览选择。媒体生产按类型整批完成，尽快交付可观看的 Remotion 预览。

当前版本：`0.1.0`

## 核心体验

每个需要用户决定的阶段都采用同一套表达方式：

```text
推荐：一套可以直接接受的默认方案
依据：内容、受众、平台、时长、素材或成本事实
可调整项：2–4 个有边界的选择
请确认：本轮只确认一个决定
```

AI 会主动判断内容完整性、镜头数量和插画比例。单个镜头通常为 3–5 秒；超过 5 秒时，需要通过持续的信息推进、构图变化或丰富动效维持节奏。

## 四个用户决策点

1. **台词与声音**：确认推荐台词、预计时长和声音方向。
2. **分镜与素材范围**：确认镜头、关键动效时间、插画数量和可用资源。
3. **风格与代表动效**：确认代表画面、动效样例和后续一致性方向。
4. **视频预览**：选择最终导出、局部修改或指定媒体重做。

## 工作流程

```text
需求与素材
  → 推荐台词和声音
  → 用户确认 1
  → 整批配音 + 真实时长
  → 关键词毫秒时间
  → 推荐分镜、插画比例和资源范围
  → 用户确认 2
  → 推荐风格 + 代表画面和动效
  → 用户确认 3
  → 整批插画
  → Remotion 工程、字幕、动效和预览
  → 用户确认 4
  → 导出或定向重做
```

正常项目使用三个媒体生产 Agent：音频、图片和视频。另有两个分析/设计 Agent 负责关键词时间和风格动效。每个媒体 Agent 负责对应类型的整批产物，而不是按镜头、图片或字幕拆分。

## 内置 Skills

| Skill | 职责 |
| --- | --- |
| `video-director-v2` | 主动推荐方案、引导四次用户选择、维护 `workflow.json` 并调度 Agent |
| `voice-producer-v2` | 整批生成已确认配音，记录逐句和总时长 |
| `keyword-timing-v2` | 从真实配音提取关键词、数字、短语、问题和转折的毫秒时间 |
| `storyboard-director-v2` | 根据内容、真实时长和素材推荐镜头、动效时间与插画比例 |
| `visual-style-v2` | 推荐视觉与动效方向，生成有限代表样例供用户确认 |
| `illustration-producer-v2` | 在同一上下文中生成整批一致插画 |
| `remotion-video-v2` | 创建可编辑 Remotion 工程、字幕、动效、预览和用户批准的导出 |

## 快速开始

克隆仓库：

```bash
git clone https://github.com/Fantasy421/video-production-toolkit-v2.git
cd video-production-toolkit-v2
```

将仓库目录作为本地 Codex 插件源加载后，可以直接描述视频目标，例如：

```text
把“为什么 AI 工作流需要人工决策点”做成一条 60 秒、9:16 的中文知识视频。
目标受众是刚开始使用 AI 工具的职场人。请先给我推荐台词、声音和时长方案。
```

也可以从现有台词和素材开始：

```text
根据这份口播稿和素材目录，推荐镜头数量、插画比例和关键动效时间，然后引导我逐步确认。
```

## 项目恢复

每个视频项目使用一个轻量 `workflow.json` 记录：

- 当前阶段；
- 已确认的用户选择；
- 台词、分镜、音频、关键词时间、图片、工程、预览和成片路径；
- 当前推荐与待确认事项；
- 下一步动作。

当任务中断后，主任务可以根据这些信息继续给出下一步推荐。

## 局部重做

用户可以指定只重做某段配音、某几张插画、某个镜头的字幕或动效。主任务会为对应媒体类型创建新的定向 Agent，并保留其他已完成产物。
